## Decisions Made This Session

- **Popup via `window.open`**: The floating FAB popup approach (`FloatingNotePopup` + `NotePopupContext`) was scrapped. Instead, each canvas node has a Maximize2 button that opens the block in a new browser window via `window.open("/popup/{blockId}", ...)`. This scales to all block types, supports focus, and is isolated from the canvas DOM.
- **Real-time sync via BroadcastChannel**: The popup window writes to `BroadcastChannel("note-popups")` after each autosave. The canvas `InnerCanvas` component listens on the same channel and updates React node state — no polling, no websockets needed.
- **DrawingLayer coordinate fix**: The prior implementation stored `clientX - rect.left` (screen coords). After zooming/panning the canvas, saved drawings were misaligned. Fixed by wrapping all `<path>` elements in a `<g transform="translate(x,y) scale(zoom)">` and converting pointer events through the inverse transform.
- **`getOrCreateCanvas` select-then-insert**: Replaced the `upsert(ignoreDuplicates: true)` with an explicit select followed by insert only when no row exists. This eliminates a Supabase quirk where `upsert` with `ignoreDuplicates` returns `null` data in some versions.
- **Rejected alternative — WebSockets / Supabase Realtime for popup sync**: `BroadcastChannel` is sufficient because both windows share the same origin and the same browser session. Realtime would add latency and cost.
