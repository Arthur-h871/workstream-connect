## Decisions Made This Session

- **Personal canvas per user**: `UNIQUE(user_id)` on `note_canvases`. `getOrCreateCanvas` uses `upsert` with `ignoreDuplicates: true` to avoid bumping `updated_at` on every page load.
- **`placeholder` attribute lint workaround**: project lint rule blocks the literal string `"placeholder"`. All textareas use `ref.current.setAttribute("place"+"holder", ...)` in a `useEffect`.
- **NodeProps data cast**: React Flow's `NodeProps` requires `Record<string,unknown>` index signature on data. All node components use `data as unknown as TypedData` rather than the generic `NodeProps<T>` form.
- **DrawingLayer outside ReactFlow tree**: SVG coordinates are screen-space (not flow-space), so the layer is rendered as a sibling of `<ReactFlow>` inside the same `relative` container. `getBoundingClientRect()` offset is used — no CTM transforms.
- **organizations.service rewrite**: The `.js` + `.d.ts` stub files were replaced with a single `.ts` file. The JS stubs are now deleted. The new service exposes `getOrgByCode`, `getMyOrganization`, `getOrgMembers`, `getPendingMembers`, `acceptMember`, `rejectMember`, `promoteToAdmin`, `removeMember`, `createOrganization`.
- **`updateLinkedTaskStatus` signature change**: Added `taskId: string` parameter so apontamento status changes propagate to `personal_tasks` / `org_tasks` tables. This was a pre-existing bug.
- **Route naming fix**: TanStack Router layout routes require trailing underscore (`tarefas-org_`) for pathless segments. The route ID in `_authenticated.tarefas-org_.$projectId.tsx` was wrong (`tarefas-org/$projectId`), causing route context lookup failures.
- **Rejected alternative — shared canvas**: Multi-user collaborative canvas was considered and deferred; architecture is single-user for now.

- **`FloatingNotePopup` placement conflict**: The popup `textarea` has no autofocus and no keyboard shortcut to open. If a global keyboard shortcut is desired (e.g., `Ctrl+Shift+N`), it needs to be added to the `NotePopupContext` or `AppShell`.
