

## 01 - SUPORTE A SALVAMENTO DE MULTIPLOS CANVAS SEPARADOS ===========

queria que, ao abrir a pagina de notas, ela mostrasse ao usuario varias opções dos canvas que ela tem salvo, e nessa pagina, ela poderia criar, excluir ou entrar nos canvas dela

seria muito bom se essa pagina tambem tivesse comportamento de canvas, assim o usuario poderia anotar coisas sobre cada um dos canvas dele
os canvas tambem podem ter outros canvas cadastrados dentro deles, ou seja, essa feature seria adicionar um canva main no topo de tudo


## 02 - ADIÇÃO DE TODO LISTS =========================================

essa feature consiste em uma função interna dos quadros, que permite o usuario criar todo lists dentro deles

para fazer isso, o usuario precisaria escrever algo como:

 - uma tarefa
 - outra tarefa
 - mais uma tarefa

o codigo deve interpretar isso como uma todo list, e criar uma lista de tarefas dentro do quadro, com checkboxes para marcar as tarefas como concluídas
é importante que as tarefas marcadas como concluidas sejam salvas sempre.

## 03 - ADIÇÃO DE CONEXÃO DE SETAS ENTRE QUADROS =====================

inspirado no milanote, essa feature consiste em que o usuario, quando adicionar uma seta ao quadro, possa conectar as setas nos quadros
é importante que a seta possa ser fixada em qualquer lugar das bordas dos quadros

as setas tambem podem ser conectadas a itens individuais das todo lists
